Guitar Tuning by Ear — Standard E A D G B E

Before you practise, check that your guitar is in tune. This free reference video presents the six open strings of standard guitar tuning, from the lowest-pitched to the highest-pitched string. There is no speech or backing music: only reference tones and clear note names and frequencies.

How to practise

  1. Play your sixth (thickest) string and compare it with E2, then work toward the first (thinnest) string E4.
  2. Standard tuning is E2 – A2 – D3 – G3 – B3 – E4, using A4 = 440 Hz as the reference.
  3. Adjust the string until its pitch matches the reference sound. Use a comfortable listening volume and replay any tone if needed.
